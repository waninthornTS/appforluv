# 💗 Our Little World

แอปเล็กๆ สำหรับคู่รัก (PWA) ติดตั้งลงหน้าจอ iPhone ได้เหมือนแอปจริง
เขียนด้วย **HTML + CSS + JavaScript ล้วน** ไม่มี build step: แก้ไฟล์แล้วอัปขึ้น GitHub Pages ได้ทันที

## ✨ ฟีเจอร์

| หน้า | มีอะไรบ้าง |
|---|---|
| 🏠 **หน้าแรก** | ตัวละคร **Ploy** (ผมหน้าม้าสีดำ ใส่แว่น แต่งตัวทะมัดทะแมง) และ **Dream** (ผมยาวสีดำ กอดตุ๊กตาหมี) แตะเพื่อให้พูด, ตัวนับวันที่คบกัน (D+, ปี/เดือน/วัน) เริ่ม 22 ส.ค. 2569, นับถอยหลังวันสำคัญ (ครบ 100 วัน, ครบรอบปี, วันเกิด), นัดถัดไป, ความทรงจำล่าสุด |
| 📔 **ไดอารี่** | บันทึกว่าไปดูหนังเรื่องอะไร (โรงไหน ใครเลือก ให้กี่หัวใจ) รวมถึงไปกินข้าว ไปเดท ฯลฯ อัปโหลดได้สูงสุด 6 รูปต่อรายการ แสดงเป็นรูปโพลารอยด์ |
| 🗓️ **ปฏิทิน** | ปฏิทินภาษาไทย (พ.ศ.) รวมนัดเดท ทริป วันครบรอบ/ครบเดือน/ทุก 100 วัน วันเกิด และไดอารี่ไว้ในที่เดียว ลงนัดล่วงหน้าได้ และแสดงรายการ 60 วันข้างหน้า |
| ✈️ **เที่ยว (Travel mode)** | ทริปในประเทศ (เลือกจังหวัด) และต่างประเทศ (มีธงชาติ) สถานะ อยากไป → วางแผนแล้ว → ไปแล้ว พร้อมนับถอยหลัง งบประมาณ เช็คลิสต์เตรียมของ (มีรายการตั้งต้นให้) และ "พาสปอร์ต" สะสมแสตมป์ประเทศ/จังหวัดที่ไปมาแล้ว |
| 💞 **เรา** | แก้วันครบรอบ / วันเกิดของ Ploy และ Dream, สำรอง / กู้คืน / รวมข้อมูล |

- นาฬิกาเล็กๆ ด้านบนทุกหน้า และพื้นหลังทั้งแอปเปลี่ยนตามเวลาจริง: เช้า 🌅 / กลางวัน ☀️ / เย็น 🌇 / กลางคืน 🌙 (มีดาวและพระจันทร์)
- ใช้งานออฟไลน์ได้ (Service Worker)
- รูปภาพถูกย่อขนาดอัตโนมัติก่อนเก็บ เพื่อประหยัดพื้นที่

## 📁 โครงสร้างโปรเจกต์

```
index.html              หน้าเดียวของแอป + แถบเมนูด้านล่าง
manifest.webmanifest    ข้อมูล PWA (ชื่อแอป ไอคอน สี)
sw.js                   Service worker (ใช้ออฟไลน์ได้)
css/style.css           ธีมพาสเทลทั้งหมด (สีหลักอยู่ใน :root ด้านบนสุด)
js/app.js               router (#home, #diary, #calendar, #travel, #me)
js/db.js                IndexedDB (ที่เก็บข้อมูลในเครื่อง)
js/store.js             โปรไฟล์, collections, สูตรคำนวณ Love Level
js/utils.js             วันที่ภาษาไทย, bottom sheet, toast, หัวใจลอย
js/photos.js            ย่อรูป / เก็บรูป / ตัวเลือกรูป / ดูรูปเต็มจอ
js/characters.js        ตัวละคร SVG (เพิ่มทรงผม ชุด หรือเครื่องประดับได้ที่นี่)
js/sky.js               นาฬิกา + ท้องฟ้ากลางวัน/กลางคืน (ปรับช่วงเวลาได้ใน period())
js/data/places.js       รายชื่อจังหวัด ประเทศ และเช็คลิสต์ตั้งต้น
js/views/*.js           แต่ละหน้า
icons/                  ไอคอนแอป (สร้างใหม่ได้ด้วย tools/make-icons.js)
tools/serve.js          เซิร์ฟเวอร์สำหรับทดสอบในเครื่อง
tools/gallery.html      ดูตัวละครทุกทรงผม/ชุด/เครื่องประดับพร้อมกัน (http://localhost:5173/tools/gallery.html)
```

## 💻 ทดสอบในเครื่อง

ต้องมี [Node.js](https://nodejs.org) (ไม่ต้อง `npm install` อะไรเลย)

```bash
node tools/serve.js
```

แล้วเปิด http://localhost:5173 (ใน Chrome กด F12 แล้วเลือกโหมดมือถือ จะเห็นหน้าตาเหมือนบน iPhone)

> ⚠️ เปิดไฟล์ `index.html` ด้วยการดับเบิลคลิกตรงๆ ไม่ได้ เพราะ ES modules ต้องรันผ่านเซิร์ฟเวอร์

## 🚀 อัปขึ้น GitHub Pages (ฟรี)

1. สร้าง repository ใหม่บน GitHub เช่น `our-little-world` (ตั้งเป็น Public)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป (ลากวางในหน้าเว็บ GitHub ก็ได้ หรือใช้คำสั่งด้านล่าง)
   ```bash
   git init
   git add .
   git commit -m "Our Little World"
   git branch -M main
   git remote add origin https://github.com/<username>/our-little-world.git
   git push -u origin main
   ```
3. ไปที่ **Settings → Pages** แล้วตั้ง Source เป็น **Deploy from a branch**, Branch เป็น **main** โฟลเดอร์ **/ (root)** แล้วกด Save
4. รอ 1–2 นาที แอปจะอยู่ที่ `https://<username>.github.io/our-little-world/`

## 📱 ติดตั้งลง iPhone

1. เปิดลิงก์ด้านบนด้วย **Safari**
2. กดปุ่ม **แชร์** (สี่เหลี่ยมมีลูกศรชี้ขึ้น)
3. เลือก **"เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen)** แล้วกด **เพิ่ม**
4. แอปจะมีไอคอนหัวใจบนหน้าจอ และเปิดแบบเต็มจอเหมือนแอปจริง

## 💾 ข้อมูลเก็บไว้ที่ไหน (สำคัญ)

- ข้อมูลและรูปทั้งหมดเก็บอยู่ **ในเครื่องของแต่ละคน** (IndexedDB) ไม่มีการส่งไปเซิร์ฟเวอร์
- ข้อมูลในแอปที่ติดตั้งลงหน้าจอโฮม **แยกจาก Safari** ถ้าลบไอคอนแอปทิ้ง ข้อมูลจะหายไปด้วย
- **ซิงก์กับแฟน:** ไปที่หน้า "เรา" → **สำรองข้อมูล** → ส่งไฟล์ `.json` ให้แฟน (AirDrop / LINE) → อีกเครื่องกด **รวมข้อมูลจากแฟน** รายการจากทั้งสองเครื่องจะถูกรวมกัน (รายการที่แก้ทีหลังจะทับรายการเก่า)
- ควรกดสำรองข้อมูลเก็บไว้ใน Files / iCloud เป็นระยะ

## 🛠️ พัฒนาต่อ

- **เปลี่ยนธีมสี:** แก้ตัวแปรใน `:root` บนสุดของ `css/style.css`
- **ปรับหน้าตา Ploy / Dream:** แก้ค่า `PLOY` และ `DREAM` ด้านบนของ `js/characters.js` (ทรงผม สีผม ชุด สีชุด เครื่องประดับ ตุ๊กตาหมี)
- **เพิ่มทรงผม / ชุด / เครื่องประดับ:** แก้ใน `js/characters.js` (เพิ่มชื่อใน `HAIR_STYLES`, `OUTFITS`, `ACCESSORIES` แล้ววาด SVG เพิ่มใน `hairParts` / `bodySVG` / `accSVG`) แล้วเปิด `tools/gallery.html` เพื่อดูผลทุกแบบพร้อมกัน
- **เพิ่มประโยคที่ตัวละครพูด:** แก้ `LINES` ใน `js/views/home.js` (`A` = Ploy, `B` = Dream, `{o}` = ชื่ออีกคน)
- **เปลี่ยนชื่อ / วันครบรอบเริ่มต้น:** แก้ `DEFAULT_PROFILE` ใน `js/store.js` แล้วเพิ่มเลข `version`
- **เพิ่มหน้าใหม่:** สร้าง `js/views/xxx.js` ที่ export `render(el)` (และ `fab` ถ้าต้องการปุ่ม ＋) แล้วเพิ่มใน `routes` ของ `js/app.js` กับแท็บใน `index.html`
- **ซิงก์ข้อมูลแบบเรียลไทม์ระหว่างสองเครื่อง:** GitHub Pages เป็นเว็บแบบ static จึงไม่มีฐานข้อมูลกลาง ถ้าต้องการให้เห็นข้อมูลชุดเดียวกันทันที ให้ต่อกับบริการฟรีอย่าง **Firebase (Firestore + Storage)** หรือ **Supabase** โดยแก้เฉพาะ `js/db.js` และ `js/photos.js` เพราะทุกหน้าเรียกข้อมูลผ่านสองไฟล์นี้
- **อัปเดตเวอร์ชัน:** เมื่อเพิ่มไฟล์ JS/CSS ใหม่ ให้ใส่ชื่อไฟล์ใน `ASSETS` ของ `sw.js` และเปลี่ยน `VERSION`
- **สร้างไอคอนใหม่:** แก้สีหรือรูปใน `tools/make-icons.js` แล้วรัน `node tools/make-icons.js`
