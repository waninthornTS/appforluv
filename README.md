# 💗 Ploy & Dream — Our Little World

แอปคู่รักของ Ploy & Dream (PWA) ติดตั้งลงหน้าจอ iPhone ได้เหมือนแอปจริง ใช้งานออฟไลน์ได้
เขียนด้วย **React + TypeScript + Vite** และอัปขึ้น **GitHub Pages ฟรี** แบบอัตโนมัติ

## ✨ ฟีเจอร์

| หน้า | มีอะไรบ้าง |

| 🗓️ **ปฏิทิน** | ปฏิทินไทย (พ.ศ.) รวมนัด ทริป วันครบรอบ/ครบเดือน/ทุก 100 วัน วันเกิด และไดอารี่ไว้ในที่เดียว + รายการ 60 วันข้างหน้า |

## 🧸 ใส่รูปตัวละครแบบ 3D

วางไฟล์รูป **พื้นหลังโปร่งใส ยืนเต็มตัว** ไว้ที่ `src/assets/characters/`

```
src/assets/characters/ploy.png
src/assets/characters/dream.png
```

ตอนนี้ใส่รูปที่ตัดจากภาพ 3D ไว้แล้ว ถ้าอยากเปลี่ยนรูปใหม่ แค่วางไฟล์ทับชื่อเดิม แอปจะใช้รูปใหม่เองอัตโนมัติ (รองรับ `.png` และ `.webp`, แนะนำขนาดประมาณ 600×800 px และตัดขอบว่างให้น้อยที่สุด)
ถ้ายังไม่มีไฟล์ แอปจะใช้ตัวละครแบบ SVG ที่วาดไว้แทน

## 💻 รันในเครื่อง

ต้องมี [Node.js](https://nodejs.org) เวอร์ชัน 20 ขึ้นไป

```bash
npm install
```

```bash
npm run dev
```

แล้วเปิดลิงก์ที่ขึ้นในหน้าจอ (ปกติคือ http://localhost:5173)
ถ้าใช้ Wi-Fi เดียวกัน เปิดลิงก์ `Network:` ด้วย iPhone เพื่อลองบนมือถือจริงได้เลย

คำสั่งอื่นๆ: `npm run build` (สร้างไฟล์จริงในโฟลเดอร์ `dist/`), `npm run preview` (ลองไฟล์จริง), `npm run typecheck`

## 🚀 อัปขึ้น GitHub Pages (อัตโนมัติ)

1. สร้าง repository ใหม่บน GitHub แล้ว push โค้ดขึ้นไป (ไม่ต้องอัปโฟลเดอร์ `node_modules` และ `dist`)
   ```bash
   git init
   git add .
   git commit -m "Ploy & Dream v2"
   git branch -M main
   git remote add origin https://github.com/<username>/<repo>.git
   git push -u origin main
   ```
2. ไปที่ **Settings → Pages** แล้วตั้ง **Source = GitHub Actions**
3. รอ 1–2 นาที (ดูความคืบหน้าได้ที่แท็บ **Actions**) แอปจะอยู่ที่ `https://<username>.github.io/<repo>/`
4. ครั้งต่อไปแค่ push โค้ดใหม่ GitHub จะสร้างและอัปให้เองทุกครั้ง

> ถ้าเคยใช้เวอร์ชันเก่าใน repo เดิม ข้อมูลในเครื่อง (ไดอารี่ นัด ทริป รูป) จะยังอยู่ เพราะใช้ฐานข้อมูลชื่อเดิม

## ☁️ ซิงก์ข้อมูล 2 เครื่อง

ข้อมูลทั้งหมด (ไดอารี่ นัด ทริป รูป ชอบ/ไม่ชอบ) ซิงก์ผ่าน **Supabase** (ฟรี) แบบเรียลไทม์
ฝั่งหนึ่งบันทึก อีกฝั่งเห็นภายในไม่กี่วินาที ไม่มีเน็ตก็ใช้ได้ แล้วจะส่งขึ้นเองเมื่อต่อเน็ต

👉 ทำตาม **[SUPABASE_SETUP.md](SUPABASE_SETUP.md)** ครั้งเดียว (ประมาณ 10 นาที)
ถ้ายังไม่ได้ตั้งค่า แอปจะเก็บข้อมูลในเครื่องอย่างเดียว

## 📁 โครงสร้างโค้ด

```
src/
  cloud.config.ts           ใส่ URL + anon key ของ Supabase
  main.tsx, App.tsx         จุดเริ่มแอป, สลับหน้าตามแท็บ (#home, #diary, ...)
  lib/                      ข้อมูลและฟังก์ชันช่วย
    store.ts                ข้อมูล Ploy & Dream (ชื่อ วันเกิด วันครบรอบ) + hook โหลดข้อมูลแบบ reactive
    db.ts                   IndexedDB (เก็บในเครื่อง ใช้เป็นแคชออฟไลน์)
    sync.ts                 ซิงก์กับ Supabase (ไม่ต้องล็อกอิน): คิวรอส่ง, ดึงของใหม่, เรียลไทม์
    photos.ts               ย่อรูป/เก็บรูป
    date.ts, sky.ts, meta.ts, places.ts, types.ts
  characters/               ตัวละคร (ใช้รูป PNG ถ้ามี ไม่งั้นใช้ SVG)
  ui/                       bottom sheet, toast, ปุ่ม, ตัวเลือกรูป, แถบเมนู, ท้องฟ้า+นาฬิกา
  features/                 แต่ละหน้า: home, diary, calendar, travel, me
  styles/app.css            ธีมสีทั้งหมด (แก้สีหลักที่ :root ด้านบน)
supabase/schema.sql         สร้างตาราง + ที่เก็บรูปบน Supabase (no-login.sql = อัปเดตจากเวอร์ชันมีล็อกอิน)
public/icons/               ไอคอนแอป (สร้างใหม่ได้ด้วย npm run icons)
legacy/                     โค้ดเวอร์ชันเก่า (HTML/JS ล้วน) เก็บไว้ดูเฉยๆ ลบทิ้งได้
```
